ok so currently this implementation works (I need to find a way to test it against a production grate implementation)
it's ugly but it at least represent something that do something end to end, it takes the .safetensor file, transform it
into a reader, and gives it to `Safetensors.zig`, then `Safetensors.zig` outputs a slice of `ParsedTensorMetaData` which correspond
to the different layers/ops of the model, and their relative_start/end offsets (which is absolute when adding `positionnal_binary_data_start`)
first we get the first 8 bytes, which indicates the size of the json header, that encodes the different layers/ops. Then I start consuming
that json, and unmarshall it into typed structs. Then the output is ordered by relative offsets

This is then fed to the TensorBuilder, which takes this slice, and start merging each `JsonTensorMetadata` into a struct, which represent
one unit of concurrency this then is passed to the `Dequantizer` which dequantized weights. Finally the weights are written to the output file.
